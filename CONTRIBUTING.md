# Contributing to CompeteScope Agent

Thanks for your interest in contributing!

## Getting Started

```bash
git clone https://github.com/xizhilanre/compete-scope-agent.git
cd compete-scope-agent
# See README.md for setup instructions
```

## Branch Strategy

- `main` — production branch, protected
- `develop` — integration branch for feature work
- Feature branches — `feature/<description>` from `develop`

## Workflow

1. Create a feature branch from `develop`
2. Make your changes with clear commits
3. Open a PR targeting `develop`
4. Ensure CI passes and get a review
5. PR merged via squash or rebase

## Conventions

- Follow existing code style and project structure
- Write meaningful commit messages (English preferred)
- Add tests for new functionality
- Keep PRs focused — one concern per PR
